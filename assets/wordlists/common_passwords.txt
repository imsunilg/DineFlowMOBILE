# VaultLock common-password list
#
# A small, bundled sample of passwords that appear near the top of every
# public breach-corpus frequency list (rockyou-style top lists, the NCSC's
# published "top 100k" extract, and the usual regional/name/keyboard-walk
# families). It exists so the strength checker can say "this is a password
# other people already use" without ever touching a network.
#
# This is deliberately NOT a breach lookup. VaultLock is 100% offline: it
# cannot and does not check whether a specific password appeared in a specific
# breach. The security dashboard says so in as many words. This file only
# answers the much weaker, purely local question "is this one of the obvious
# ones?".
#
# Format: one password per line, lowercase where the original is caseless.
# Lines beginning with '#' and blank lines are ignored. Matching is
# case-insensitive, so "PASSWORD" and "Password" both hit the "password" row.
